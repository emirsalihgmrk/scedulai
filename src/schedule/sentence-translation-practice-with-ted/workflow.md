# 15 Sentences Per Day with TEDx Workflow

## Program Overview

"Learning begins with learning how to learn."

This program helps users learn English through practical sentence construction using authentic TEDx video content. Users engage with real-world vocabulary and sentence structures in context, building both comprehension and expression skills over a structured 1.5-day cycle.

**Program Duration:** 1.5 days per cycle (repeatable)  
**Daily Commitment:** ~20-30 minutes  
**Learning Method:** Active Recall + Spaced Repetition + Context-Based Learning

---

## Workflow Phases

### Phase 1: Video Selection

**Who provides the video?**

- Option A: System recommends a TEDx video link based on user's language level and interests
- Option B: User selects and shares a TEDx video link or transcript

**Prerequisites:**

- Video must have subtitles available
- Video should contain diverse vocabulary and interesting sentence structures
- Estimated video length: 5-15 minutes

---

### Phase 2: Day 1 — First 15 Sentences (Foundation)

**Step 1: Watch with Native Language Subtitles**

- User watches the TEDx video with subtitles in their native language
- Goal: Understand overall context and identify key vocabulary/structures

**Step 2: AI-Generated Sentence Prompts**

- Chat bot analyzes the video and selects key vocabulary/sentence structures from it
- Chat bot creates 15 sentences in the user's native language (Turkish, French, etc.)
- Each sentence incorporates one or more of the target words/structures from the video
- Sentences follow similar grammatical patterns to those in the video

**Step 3: Translation Challenge**

- User receives Sentence 1 in their native language
- User translates it to English
- User submits translation

**Step 4: Error Correction & Feedback**

- Chat bot evaluates the translation:
  - Identifies grammatical errors
  - Provides vocabulary suggestions (if word choice is non-idiomatic)
  - Highlights any missed target vocabulary/structures
- Chat bot provides corrective feedback and explanations
- Chat bot presents Sentence 2 (next sentence)

**Step 5: Repeat for All 15 Sentences**

- User completes sentences 1-15 following the same cycle
- Each completed sentence builds confidence and reinforces vocabulary

**Output:** User has completed 15 translations with personalized feedback

---

### Phase 3: Day 2 — Next 15 Sentences (Reinforcement)

**Step 1: Review & Retake**

- User receives another set of 15 sentences (new or reinforced versions from Phase 2)
- Chat bot may prioritize target words/structures where user made errors on Day 1
- Same workflow as Day 1: native language → translate → receive feedback

**Output:** User has completed 30 total translations; vocabulary/structures are reinforced

---

### Phase 4: Day 1.5 — Validation Phase (After Completing 30 Sentences)

**Step 1: Watch Without Subtitles**

- User watches the same TEDx video again, but WITHOUT subtitles
- Goal: Test listening comprehension and recognize learned vocabulary in context
- Chat bot can optionally provide a transcript for reference after viewing

**Step 2: Comprehension Check (Optional)**

- Chat bot asks comprehension questions about the video (Q&A format)
- User responds and receives feedback
- This validates that learning from the program transferred to actual video understanding

**Output:** User has validated comprehension and completed the cycle

---

## Cycle Completion & Continuation

Once a user completes Phases 1-4 for one video:

✅ **Cycle is Complete**

- Progress is logged (date, video, # sentences completed, accuracy rate)
- User can view their success rate and historical progress
- User is ready to start a new cycle with a different video

**Continuation Options:**

- Start a new cycle with a recommended or user-selected video
- Receive email reminder (if enabled) to start the next cycle
- Review previous vocabulary from earlier cycles (spaced repetition)

---

## Key Learning Principles

| Principle                    | Implementation                                                        |
| ---------------------------- | --------------------------------------------------------------------- |
| **Active Recall**            | User must generate translations without hints                         |
| **Spaced Repetition**        | Same vocabulary appears across multiple sentences and days            |
| **Contextual Learning**      | All vocabulary comes from authentic video content                     |
| **Immediate Feedback**       | Chat bot provides corrections immediately after each translation      |
| **Comprehension Validation** | Listening to full video reinforces learned structures                 |
| **Consistent Difficulty**    | Vocabulary/structures matched to video content, not artificial levels |

---

## User Data Tracking

The program tracks:

- ✓ Words/structures attempted (with timestamps)
- ✓ Errors made (error type, corrected form)
- ✓ Translation accuracy (percentage correct per day)
- ✓ Vocabulary mastery progression (over multiple cycles)
- ✓ Success rate (overall accuracy across all sentences)

This data enables:

- Personalized future sentence selection (targeting weak areas)
- Progress visualization (show user improvement over time)
- Algorithm refinement (better sentence difficulty matching)
